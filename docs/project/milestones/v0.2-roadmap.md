# Milestone: v0.2 and Beyond

**State: directional roadmap; scope is not yet frozen.** Expand only after v0.1 has reproducible Mini and OVAT artifacts.

## v0.2 — Model scale and experiment breadth

- Add selected 1B–3B model profiles.
- Run LoRA-rank ablations and broader compute/quality comparisons.
- Compare 8GB and larger single-GPU profiles.
- Improve automated experiment reports and provenance.

## v0.3 — Data-centric post-training

- Score dataset quality and study size, difficulty, source distribution and data mixtures.
- Add synthetic-data generation/filtering only with measurable quality and contamination gates.
- Strengthen contamination analysis.

## v0.4 — Alignment and RL breadth

- Consider KTO / ORPO / CPO-family and additional GRPO variants.
- Add reward-design and optional process-level verification studies under the same evaluation contract.

## v0.5 — Data/model flywheel

- Mine model failures, propose data updates, add data CI gates, and iterate train → evaluate → gap analysis → data update with stronger lineage.

## v0.6 — Agent and tool RL

- Add tool-call environments, deterministic task rewards and trajectory datasets for small-model agent post-training.

## v1.0 — Reproducible post-training research platform

- Mature the experiment registry, resource/effectiveness comparisons and public result catalog.
- Add multi-GPU profiles without losing the single-GPU learning path.
- Standardize Data / Training / Evaluation / Experiment interfaces.

The project is not intended to become a general-purpose distributed training framework. Training engines remain external dependencies unless a missing capability blocks the experiment methodology.
