# Milestone: v0.1 RTX 4060 Smoke

**State: complete for smoke feasibility and instrumentation.** This milestone is not the v0.1 release and does not establish effect sizes.

## Reference run

- Date: 2026-10-15 (Asia/Shanghai)
- Hardware: RTX 4060 Laptop GPU, 8GB
- Runtime: Windows, Python 3.10.11, CUDA 12.6, PyTorch 2.14.1+cu126, ms-swift 4.5.3, EvalScope 1.12.0
- Detailed evidence: [`../../../runs/smoke/RUN_REPORT_zh.md`](../../../runs/smoke/RUN_REPORT_zh.md)

## Gates reached

- Base → PEFT-CPT → M1 → SFT → M2 training and merge succeeded.
- Full-CPT 5-step BF16 feasibility probe passed under its short diagnostic profile.
- DPO, original SimPO (`cpo_alpha=0`), GRPO-standard and GRPO-lowmem each completed 20 optimizer steps and merged.
- Standard GRPO recorded KL; lowmem uses `beta=0`, so KL is N/A. Both recorded reward components and completion clipping.
- GSM8K, MATH-500, internal math and domain PPL were run for Base, M1 and M2. M2, DPO and SimPO shared the 3-pair held-out preference evaluator.
- Unit tests: 54 passed. Compile, example-data and dependency checks passed.

## Limits carried forward

- The OpenR1 smoke build produced 197/200 SFT examples, 9/200 preference pairs, 3/50 preference-eval pairs and 200/200 GRPO prompts. The preference sample is too small for quality claims.
- DPO, SimPO and GRPO merged models have not yet received the unified task benchmark evaluation.
- GRPO completion clipping averaged 90% (standard) and 91.25% (lowmem), so generation-length calibration is required before Mini.
- Ruff reported 45 findings at the end of this run.
- Full-CPT evidence is specific to BF16, batch 1, sequence length 512 and five steps. It does not imply full-scale CPT fit or convergence.
