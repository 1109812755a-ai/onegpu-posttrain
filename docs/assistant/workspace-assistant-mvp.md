# 工作区实验助手 MVP 使用与数据说明

本文说明当前工作区助手入口的能力、配置及本地数据处理方式。

## 能力范围

首版回答整个工作区内的三类问题：近期失败运行、评测结果比较、模型/运行到数据来源的追溯。回答由工作区中的结构化运行、配置、评测、质量和血缘摘要支撑，并在结论附近保留证据引用。证据不足、对象不明、状态部分完成或比较条件不一致时，助手应说明限制并请求补充信息。

助手只读。它不会运行 shell/Python、启动训练或评测、生成数据、编辑实验配置、读取任意路径或调用 MCP/联网搜索。用户创建的专用助手只能调整名称和角色指引，不能改变这些能力边界。

专用助手支持用自然语言描述需求生成本地配置草稿。草稿只填入名称和角色指引，不调用模型、不保存，需用户检查编辑后再点击“创建助手”；所有专用助手仍共享相同只读证据范围。

## 百炼模型与启用

当前默认使用 AgentScope `ReActAgent` 运行时和工作区只读工具；旧版基础助手只作为显式回退，不会在 AgentScope 出错时自动切换。安装 UI 时同时安装 AgentScope：

```powershell
pip install -e ".[ui,assistant-agentscope]"
```

助手使用项目已登记的 `dashscope-qwen3.6-plus-local` profile，模型为 `qwen3.6-plus`，服务地址固定为 DashScope OpenAI 兼容接口。浏览器请求不接收 API Key 或自定义 endpoint。

服务端从工作区的 `.env.local` 读取 `ONEGPU_SYNTHETIC_API_KEY`。请在本机配置该环境变量或放入本地 `.env.local`，不要提交 `.env.local`，不要把密钥贴入聊天。没有凭据时，助手应保持可浏览本地证据，但不会完成模型回答。

UI 通过项目现有命令启动：

```powershell
onegpu-posttrain serve-ui --workspace .
```

该命令默认绑定本机 `127.0.0.1:8765`。助手不需要也不应启用 `--allow-remote`。

诊断或兼容性排查时，可以临时显式回退到基础助手：

```powershell
$env:ONEGPU_ASSISTANT_RUNTIME = "legacy"
onegpu-posttrain serve-ui --workspace .
```

AgentScope 调用失败会在会话中显示失败原因和本轮已查到的证据；系统不会把它伪装成成功的基础助手回答。

## 数据外发与用户确认

首次调用百炼前，界面必须明确提示：本轮问题、当前助手角色指引、必要的结构化实验摘要、有限的近期对话上下文会发送到阿里云百炼处理。用户在界面明确确认后，工作区才记录授权状态；没有确认时只允许本地检索和展示确认说明，不调用模型服务。

默认不发送 API Key、`.env.local` 内容、原始数据集样本、完整日志、工作区绝对路径或任意文件正文。提交给模型的证据是助手证据适配器投影出的有限字段；调用仍需经过上下文预算检查。已同意的状态保存在工作区本地助手会话元数据中，可在会话页面查看。

## 工作区本地状态

会话、任务和专用助手配置保存在：

```text
.onegpu-posttrain/assistant/
```

它与 `runs/`、`artifacts/` 和数据集产物分开。会话和任务是本机工作区状态，不会自动同步到云端。备份或迁移工作区时，可按需备份此目录；删除助手会话不会删除实验记录。

## 证据限制与恢复

- 助手回答以当前工作区可读取的记录为准；缺失或旧版血缘、未登记数据集、未完成评测不会被补猜。
- 评测差值仅在协议、评测数据集、指标可比性身份及覆盖分母匹配时计算。协议不同或记录部分完成时，助手应抑制差值或标为部分结果。
- 证据中的本地链接用于跳回数据、运行或分析工作台；链接可见不代表内容已经独立复核。
- 百炼未配置、超时或返回无效结构时，失败状态保存在本地任务记录。修复配置或连接后，可以在同一会话重新提问；失败请求不会被当成实验结论。
- 用户可以重新打开本地会话；任务、会话或证据缺失时，页面应显示未知/缺失状态，不静默恢复成旧事实。

## 固定问题集

助手页提供本地固定 fixture 评估，覆盖近期失败运行、评测比较、血缘、歧义、缺失证据、部分/失败评测、模拟百炼故障、外发 canary 和因果推断边界。该评估使用确定性模拟适配器，不会调用百炼；结果按问题集版本、Harness 身份和配置身份写入工作区助手目录。它检查程序边界，不代表真实模型回答质量。

## 可选 Langfuse 观测

Langfuse 默认关闭。只有显式设置 `ONEGPU_ASSISTANT_LANGFUSE_ENABLED=true`，并配置 API 凭据和地址后才会发送 trace。可安装可选依赖：

```powershell
pip install -e ".[ui,assistant-observability]"
```

在服务进程环境或本地 `.env.local` 中配置 `LANGFUSE_PUBLIC_KEY`、`LANGFUSE_SECRET_KEY` 和 `LANGFUSE_BASE_URL`。WSL 自托管实例需要填写 Windows 工作台可访问的地址；不要假定 WSL IP 固定。经验证，本环境 WSL 服务在 WSL 内健康检查为 HTTP 200；Windows 访问 WSL 当前网络地址也返回 HTTP 200，NAT 模式的 `localhost:3000` 不可达。助手页的观测状态可手动检查连接。配置发生变化后需重启工作区服务。

Trace 只记录任务、会话、助手及模型身份、状态、耗时、模型尝试与请求次数、只读工具名称和调用数、证据 ID/版本、记忆 ID 和摘要版本；不发送用户问题、提示词、回答、证据摘要、记忆正文或压缩摘要正文。每条本地任务保存 trace ID 和可打开的 trace 地址。Langfuse 未配置、SDK 缺失或连接失败时，工作区内的会话和任务记录继续可用。
