## 百炼真实调用

| 场景 | 结果 | 工具/模型请求 | 人工复核 |

无证据场景首次复测曾因 AgentScope 未返回结构化结束结果而显示内部错误。已增加平台侧安全澄清兜底，并补自动化测试；修复后的百炼复测以 `needs_clarification` 完成。已有证据但缺少结构化答案仍明确失败，不降级成无依据结论。

## 当前限制

- 百炼工具调用延迟不稳定；真实比较约 111 秒，部分查询会更久。页面会显示分析中状态，单轮超时上限为 180 秒。
- 百炼未返回稳定的 token 使用计数；当前记录请求次数和耗时，不虚报 token 用量。
- Langfuse 默认关闭。本轮验证的是安全的任务级元数据记录；Langfuse 连接故障降级和服务端浏览器全流程仍需单独检查。
- 真实回答质量目前只覆盖上述代表性场景，不能据此推断所有实验问题都已解决。
