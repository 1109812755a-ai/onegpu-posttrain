# ADR-002：受限的本地数据策略编辑器

日期：2026-10-17。状态：采用，作为 `data-policy-experiments` OpenSpec change 的实现约束。

## 背景

只读 Data 页面能展示已生成的质量与处理证据，但用户还需要在真实数据上比较筛选条件。规则预览必须复用 CLI 的数据协议和 source pool/split 逻辑，不能由浏览器单独实现一套不一致的筛选，也不能引入任务调度。

## 决定

- `serve-ui` 默认维持只读；仅 `--enable-policy-editor` 开启本机策略预览与保存。
- 服务仍绑定 `127.0.0.1`。写入/预览端点校验同源请求和每次服务进程生成的本机令牌；能力接口说明是否启用，并返回当前进程令牌给本机同源页面。
- 浏览器只引用发现的来源配置 opaque ID。来源路径/tokenizer 路径由操作员配置；页面不可提交文件路径、命令或任意输出位置。
- 预览使用共享 `execute_policy`，上限 1,000 行、30 秒、单实例；本地资源缺失时明确失败，不做远程回退。
- 保存只写到工作区内 `artifacts/data-experiments/draft-<随机ID>/` 的两份脱敏策略 JSON/YAML 与状态说明；只创建新目录、不覆盖历史文件。预览、保存和报告读取均不启动训练/外部进程。
- 比较结果只读扫描 `artifacts/data-experiments/` 下小于 2 MiB 的 JSON，返回摘要白名单字段；不通过浏览器暴露原始样本、环境转储、日志或模型权重。
- 继续使用 JSON/YAML/JSONL 和本地文件系统，不增加数据库、托管 tracker 或第三方质量框架。

## 用户体验验收

页面保留 Data 页面导航/URL 上下文和 session-only 草稿，提供阶段模板、规则解释、A/B 差异、恢复默认、源缺失提示、预览过期状态、键盘焦点及窄屏布局。比较报告以表格和文字状态呈现，质量数据与模型评测分区；不可比时保留原始分数和兼容性理由，不显示可解释成收益的 delta。无真实训练评测时显示“模型效果未评估”。

## 安全与范围

令牌用于 loopback 同源编辑防护，不等同于用户认证；不应将该服务暴露到网络。该切片不接受任意路径/命令，不运行数据写入式训练任务，不改变 CLI 作为执行入口的定位。

## 与 ADR-001 的关系

ADR-001 仍定义历史 Smoke/Data 浏览器的只读边界。本 ADR 为独立的可选策略实验面板增加受限本地写入/预览，限定在专属新目录和共享策略协议内；其它 Data 浏览与所有既有 artifact 继续只读。
