# 本地模型体验指南

## 启用与入口

模型体验仅在本机显式启用 Experiment Launcher 后可用：

```bash
onegpu-posttrain serve-ui --workspace . --enable-experiment-launcher
```

打开工作区“训练与评测 → 模型体验”。也可以在成功训练 Run 的模型交接区域选择“试用此模型”，直接带入已核验的模型身份和来源 Run。

## 模型准入

体验页只接受模型注册表中唯一、可用且摘要匹配的 Base 或 merged 模型。merged 模型还要求成功训练 Run 的 lineage 与登记身份一致。页面不会接受文件路径或任意模型仓库 ID；缺文件、摘要不符、缺少 lineage 的产物不可加载。

## 单聊与同题对照

- 单聊：选一个模型，加载后可以多轮交流；结束会话会卸载模型并释放 GPU。
- 同题对照：选择 2 到 3 个模型并输入同一问题。模型依次加载、生成、卸载，不会并发驻留多个模型；若后续模型失败，前面已经完成的回答仍会保留。
- 可调整最大新 Token（1–1024）和 Temperature（0–2）。对话历史、长度和输出均有服务端上限。

训练、正式评测、单聊和同题对照共用工作区 GPU 租约。同一时刻只允许一个本地 GPU 任务；训练或评测正在运行时，模型体验会被拒绝，模型体验期间也不能启动训练/评测。

## 隐私和结果解释

提示词、会话上下文和生成内容只留在当前服务进程内存，不写入 Run、公开日志、数据集或正式评测记录。关闭会话可清除会话上下文并卸载模型；关闭服务会结束服务内会话。体验页面没有自动保存或导出功能。

所有回复均标为“定性输出 · 未经独立验证”。模型聊天适合快速观察风格、格式和大致行为，不证明答案正确，也不替代正式阶段评测或独立人工审查。
