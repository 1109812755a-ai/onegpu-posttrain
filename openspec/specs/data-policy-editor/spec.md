# Data Policy Editor Specification

## Purpose

让个人工程师通过现有 Data 页面理解并编辑阶段数据规则，建立 A/B 对照、查看本地预览和保存可复现的配置，再追踪真实训练评测结果。交互显式呈现执行范围、缺失资源和证据状态，同时保留可独立使用的 CLI 以及默认只读浏览体验。

## Requirements

### Requirement: 阶段规则编辑支持解释和模板
界面 MUST 按阶段展示适用的规则模板，区分质量、资源和完整性设置，为规则提供含义、单位、默认值及影响说明，支持恢复默认；未实现规则不可显示为生效。

#### Scenario: 新用户配置 SFT 策略
- **WHEN** 用户选择 SFT 并复制模板
- **THEN** 可看到正确性策略、长度单位和固定约束，修改后获得字段校验反馈，CPT/GRPO 尚未支持的编辑明确标注

### Requirement: A/B 配置保留上下文与突出差异
界面 MUST 显示两组完整策略及修改项，保留来源、阶段、草稿与导航上下文；用户可复制策略并选择比较类型，单变量模式须提示额外差异。

#### Scenario: 查看来源后返回实验草稿
- **WHEN** 用户从 A/B 编辑进入来源证据再返回
- **THEN** 来源/阶段选择和未保存编辑保留，差异与验证结果仍与当前草稿对应

### Requirement: 草稿修改使旧预览过期
界面 MUST 将预览结果绑定来源、规则、tokenizer 与范围摘要；任一输入改变后，旧预览需显示过期，不能当作当前策略结果。

#### Scenario: 修改长度后旧请求晚到
- **WHEN** 用户修改规则后旧预览请求才返回
- **THEN** 旧响应不能覆盖新草稿的当前结果，界面保留过期提示并允许显式重新预览

### Requirement: 预览执行范围和输入缺失可理解
界面 MUST 在执行前展示本地来源及范围，执行后展示实测数量、停止原因和采样局限；缺少原始数据或 tokenizer 时展示对应资源缺失，不能自行下载或用示例数据替代真实结果。

#### Scenario: 只有已筛选数据可用
- **WHEN** 用户尝试对已筛选数据关闭先前的过滤规则
- **THEN** 界面解释无法恢复已删候选，允许查看该现存数据的质量，但不声称完成全源规则对照

### Requirement: 策略保存与预览通过显式本地编辑模式启用
服务 MUST 默认保持只读，并仅在显式启用本地编辑模式时接受规则保存及本地预览请求；请求必须使用受限的配置字段和已发现来源身份，禁止任意路径、脚本和命令执行。

#### Scenario: 默认只读模式收到保存请求
- **WHEN** 未启用本地编辑的服务收到策略保存请求
- **THEN** 请求被拒绝，既有读取接口和 artifact 内容保持原样，界面说明编辑模式不可用

#### Scenario: 越界路径或外站提交请求
- **WHEN** 写入/预览请求指定任意文件路径、命令或来自不允许的跨站来源
- **THEN** 服务拒绝请求，不读取越界数据、不写入现存 artifact、不启动外部进程

### Requirement: 配置导出与结果展示支持现有 CLI
界面 MUST 导出经过共享校验的策略/实验配置及可复制 CLI 指令，并显示执行前缺失项；本切片的页面不直接启动训练，模型比较仅消费实际关联的运行和评测。

#### Scenario: 保存计划后尚未执行训练
- **WHEN** 用户保存或导出 A/B 计划但没有相应 run
- **THEN** 显示数据准备状态、后续命令与模型效果未评估，不能显示成功训练或能力提升

### Requirement: 可用性是可验证的交付要求
界面 MUST 支持键盘编辑、清楚焦点、窄屏访问、非纯颜色状态、指标定义及分母，并覆盖加载、空、缺失、错误和过期状态；图形提供表格替代。

#### Scenario: 用户完成规则对照任务
- **WHEN** 用户仅用键盘或窄屏完成选择来源、修改规则、预览、保存/导出并返回结果
- **THEN** 关键操作与差异可发现，失败时保留草稿并给出可执行下一步，指标和来源可追查
