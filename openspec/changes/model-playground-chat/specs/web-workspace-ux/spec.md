# Spec Delta

## ADDED Requirements

### Requirement: 模型体验有稳定入口并保留来源上下文
训练与评测工作区 SHALL 提供可发现的模型体验视图；Run 详情 SHALL 可将已核验模型身份交给模型体验页，且用户能够返回原 Run。

#### Scenario: 从工作区打开模型体验
- **WHEN** 用户在训练与评测模块选择模型体验
- **THEN** 页面展示模型选择与对话/同题对照操作，并将模型身份和阶段作为清晰上下文

#### Scenario: 从 Run 试用模型
- **WHEN** 用户从成功 Run 选择“试用此模型”
- **THEN** 模型体验打开并预选该 Run 实际产出的已核验模型，且保留返回该 Run 详情的入口

#### Scenario: Run 模型当前不可体验
- **WHEN** Run 没有可核验或可加载的模型产物
- **THEN** 不显示可启动的试用动作，或明确说明阻断原因，不要求用户复制内部模型路径
