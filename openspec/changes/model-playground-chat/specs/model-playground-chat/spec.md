# Spec Delta

## Purpose

让用户在本机安全体验可核验的阶段模型，并通过同题对照直观看到模型输出差异，同时保持推理、正式评测与训练数据之间的边界清晰。

## ADDED Requirements

### Requirement: 仅提供身份与路径可核验的本地模型
模型体验 SHALL 仅列出阶段、模型身份、摘要和本地权重路径均可核验且当前推理器支持的模型，并显示模型阶段和来源 Run。

#### Scenario: 存在可体验的阶段模型
- **WHEN** 用户打开模型体验并选择阶段
- **THEN** 页面仅显示符合准入条件的本地模型及其阶段、模型 ID、来源 Run 信息

#### Scenario: 模型产物缺失或摘要不匹配
- **WHEN** 模型路径不可用、产物缺失或内容摘要与登记证据不符
- **THEN** 该模型不可启动推理，页面说明具体不可用原因且不尝试加载任意路径

### Requirement: 支持单模型连续对话
模型体验 SHALL 允许用户选择一个可用模型进行多轮对话，并展示生成状态、失败信息和用户可控的生成参数。

#### Scenario: 开始单模型会话
- **WHEN** 用户选择可用模型并提交消息
- **THEN** 系统使用所选模型及当前会话上下文生成回复，并显示对应模型身份和生成状态

#### Scenario: 用户停止或生成失败
- **WHEN** 用户停止生成或推理发生错误
- **THEN** 系统结束或标记本次生成，不声称生成成功，并保留此前可见的会话内容

### Requirement: 同题对照最多选择三个模型并串行推理
模型体验 SHALL 支持将同一问题提交给最多三个可用模型进行对照，并 SHALL NOT 同时将多个完整模型权重加载到本地 GPU。

#### Scenario: 同题比较多个阶段模型
- **WHEN** 用户选择二至三个模型并提交同一问题
- **THEN** 系统按序运行推理，分别展示每个模型的输出、阶段和模型身份

#### Scenario: 超过比较上限
- **WHEN** 用户尝试选择超过三个模型
- **THEN** 页面阻止增加选择并说明单次最多比较三个模型

### Requirement: 与本地 GPU 训练和评测互斥
模型体验 SHALL 遵守与本地训练和评测一致的单 GPU 活动任务约束；存在其他 GPU 任务时 SHALL 阻止启动新推理，并显示活动任务及恢复入口。

#### Scenario: 训练或评测正在占用 GPU
- **WHEN** 用户提交模型体验请求且本地 GPU 已有活动任务
- **THEN** 推理不启动，页面说明 GPU 忙碌并提供查看活动任务的入口

#### Scenario: 模型体验占用 GPU
- **WHEN** 模型正在加载或生成
- **THEN** 系统将该推理显示为活动任务并阻止并发 GPU 任务，直至模型卸载或推理终止

### Requirement: 体验结果不得冒充正式评测或训练数据
聊天与对照输出 SHALL 标记为定性体验且事实未验证；会话 SHALL NOT 自动创建训练 Run、正式评测结果、训练数据集或登记记录。

#### Scenario: 查看聊天回复
- **WHEN** 用户查看单聊或对照输出
- **THEN** 页面明确说明该输出不构成正式评测分数或正确性验证

#### Scenario: 保存或导出体验记录
- **WHEN** 用户显式选择保存或导出
- **THEN** 系统在执行前说明数据范围及去向，并仅保存用户确认的内容；未确认时不写入数据集或训练流程

### Requirement: 保留体验复现所需的模型与参数证据
每次体验输出 SHALL 可关联到模型 ID、内容摘要、阶段、来源 Run 和实际生成参数；会话内容 SHALL 保持本地受限且不写入公开日志或遥测。

#### Scenario: 查看一次模型输出的来源
- **WHEN** 用户查看某次体验输出的详情
- **THEN** 页面能够显示对应的模型身份、模型摘要、来源 Run 和生成参数

#### Scenario: 请求失败或取消
- **WHEN** 推理请求失败或被取消
- **THEN** 系统保留非敏感状态和已知模型身份，不在错误、日志或诊断响应中暴露凭据或会话提示词

### Requirement: 从成功 Run 交接到模型体验
训练 Run 详情 SHALL 为 lineage、登记身份和内容摘要均核验通过的模型产物提供“试用此模型”入口；导航只传递 model ID 与来源 Run ID，不传递或接受文件路径。

#### Scenario: 从成功 Run 试用已核验模型
- **WHEN** 用户在成功训练 Run 详情点击“试用此模型”
- **THEN** 模型体验页预选该模型，显示来源 Run，并允许用户返回来源 Run

#### Scenario: Run 模型 lineage 或摘要未通过
- **WHEN** Run 产物缺少匹配登记、唯一身份、摘要或 lineage 证据
- **THEN** 不显示可启动的模型体验入口，或说明该模型当前不满足体验条件

### Requirement: 模型体验界面支持键盘和窄屏
模型体验 SHALL 在键盘操作下可达并显示焦点状态，且在 390px 窄屏与桌面宽度下保持模型选择、输入、参数、运行状态和结果可读可操作。

#### Scenario: 窄屏使用同题对照
- **WHEN** 用户在 390px 视口选择模型并提交同题对照
- **THEN** 模型卡片和结果纵向或自适应排列，不要求横向滚动页面

#### Scenario: 键盘访问模型体验
- **WHEN** 用户只用键盘在模型体验页导航和提交
- **THEN** 模式切换、模型选择、参数、消息输入和主要操作均可聚焦且具备可见焦点
