# 设计：AgentScope 工作区实验问答

## Context

现有 FastAPI 服务使用 `WorkspaceAssistantService` 编排关键词分类、`WorkspaceEvidenceReader` 和百炼单次调用；React 页面、会话存储、授权、上下文摘要和可选 Langfuse 已存在。最近一次真实 SFT 比较问题曾被错误分类，修正后又因候选证据过多而超预算。固定 fixture 评估不代表真实百炼问答通过。

## Goals / Non-Goals

**目标：**在现有工作区内用 AgentScope 驱动有边界的模型与工具循环，提供可追溯分析并保持既有会话体验。

**非目标：**训练或评测执行、数据生成、shell/Python、任意文件访问、联网调研、MCP、多 Agent 编排与自动规划操作流程。

## Decisions

### 1. AgentScope 承担运行时

使用 AgentScope `ReActAgent`、模型适配和 `Toolkit` 实现模型决定工具调用的循环；不把 AgentScope 当作仅包装单次模型调用的库。固定经过兼容性验证的版本，检查项目 Python 3.10–3.12、Windows/WSL 和百炼工具调用兼容性。优先复用 `dashscope-qwen3.6-plus-local` 的凭据与模型约定；适配层封装 SDK 异步接口，避免阻塞 FastAPI 事件循环。以前的关键词分类与固定流程作为迁移期间可显式选择的回退，默认路径由 AgentScope 驱动；不在运行失败后静默切换并声称已成功。

### 2. 工具由平台提供并约束

在空 Toolkit 中仅注册平台只读能力：搜索和读取运行、检索评测、查询数据集与模型血缘、读取质量摘要、执行确定性评测可比性检查。工具接受结构化筛选和分页，返回有限字段、证据 ID、来源、状态和明确的缺失信息。后端验证工作区范围和参数，禁止任意路径、内置 shell/Python、文件写入、外部联网及训练执行。模型不得因角色指引获得额外权限。

评测比较先按明确的阶段、对象和时间筛选；不足两项或存在歧义时让用户选择，不靠标题子串猜测身份。比较使用现有确定性可比性逻辑核对协议、数据集、指标、覆盖分母和状态；不把不兼容的数值当作有效差值。证据引用在平台侧校验，模型不可引用未由工具返回的证据。

### 3. 上下文、预算和失败

保留现有会话、专用助手、用户确认的长期偏好和摘要；历史实验事实须重新查证。工具结果按问题相关性和分页逐步获取，限制单轮调用次数、耗时、输出和上下文，保留模型输出余量；达到限制时说明已完成内容与下一步。压缩只处理历史上下文，不静默截断必要证据、身份或比较条件。现有会话首次外发前的明确授权继续生效，不把授权提示当作模型答案。

### 4. 界面和观测

沿用独立聊天入口和默认助手，展示查找进度、实际结论、引用、限制和错误；技术记录默认收起。会话与任务仍是本地事实来源，Langfuse 为可选观测，默认只发送白名单元数据并可降级。逐次模型与工具调用关联任务 ID、状态、耗时、证据 ID 和用量；不默认发送问题、原始记录、凭据、完整日志、提示词或记忆正文。

### 5. 真实验收与迁移

保留原有可控 fixture 并新增 AgentScope 工具调用、权限与引用验证；模拟模型测试不能等同真实百炼验收。对当前工作区验证最近失败 Run、最近两次 SFT 评测、数据与模型血缘、追问、无证据、不可比和模型失败；真实百炼调用需使用已有授权并记录模型版本、证据及结果，人工核对数值和分母。保持原有存储/API 兼容，先在本地启用新路径并验证旧会话恢复；出现回归可显式切回旧路径，记录失败原因。

## Risks / Trade-offs

- [框架与模型的工具调用、结构化输出或 Python 版本不兼容] → 固定已验证版本，先做兼容性验证，失败明确阻断而不声称完成。
- [模型调用无关工具或泄露未授权内容] → 空工具集加显式白名单、参数约束、迭代与预算上限，工具结果最小化并校验引用。
- [评测记录身份不足导致无法比较] → 展示证据与缺口，要求澄清，不将推断当作比较事实。
- [模型服务不稳定或成本增加] → 限制调用次数及超时，记录可恢复状态，明确失败并允许重试。

## Migration Plan

先落实依赖和工具契约，再实现 AgentScope 运行时及现有会话适配，完成 UI 和观测后分别验证模拟与真实模型；本地确认通过后将新运行时设为默认，保留可显式回退的旧路径和已有会话数据。
