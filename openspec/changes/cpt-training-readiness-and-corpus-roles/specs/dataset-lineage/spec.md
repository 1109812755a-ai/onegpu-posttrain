# Spec Delta

## ADDED Requirements

### Requirement: 历史数据修复生成不可变的血缘后代
对已登记数据集进行角色补全、规范迁移或其他训练就绪修复 MUST 生成新的数据集身份和内容摘要，并记录输入数据集 ID/摘要、修复协议版本及可验证的处理证据；原数据集及其报告 MUST 保持不变。

#### Scenario: 可信 CPT 构建产物修复成功
- **WHEN** 系统根据校验通过的原始 manifest、构建协议和处理报告为旧 CPT 记录补充明确角色
- **THEN** 输出数据集通过新摘要和新 ID 关联到输入数据集，记录转换版本、角色计数及处理报告，并且旧数据集内容未改变

#### Scenario: 修复依据不足
- **WHEN** 历史数据缺少可验证的来源协议、原始内容摘要或唯一的处理证据
- **THEN** 修复被拒绝且不写入任何数据或登记变更，用户需重新构建或重新导入并明确声明角色
