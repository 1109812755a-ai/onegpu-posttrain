# Spec Delta

## Purpose

帮助用户快速找到最近成功训练且通过本地模型目录与血缘核验的模型，并以可维护的个人显示名区分实验产物，同时完整保留模型不可变身份和来源证据。

## ADDED Requirements

### Requirement: 最近合格模型发现与默认选择
模型体验目录 SHALL 将具有成功训练来源、可用本地权重及有效模型身份/血缘证据的模型按训练 Run 完成时间从新到旧展示；没有有效完成时间的模型 SHALL 排在有时间的模型之后。目录加载或默认选择 SHALL NOT 自动加载模型或占用 GPU。

#### Scenario: 最近成功训练模型
- **WHEN** 目录中存在多个通过核验且训练完成时间有效的模型
- **THEN** 最近完成训练的模型排在最前，并作为默认选择

#### Scenario: 缺少完成时间的旧产物
- **WHEN** 可用模型没有可解析的来源训练完成时间
- **THEN** 该模型仍可被发现，但排在有有效时间的模型之后，并使用明确的未知时间回退展示

#### Scenario: 显式 Run 深链
- **WHEN** 用户从某个 Run 的模型产物进入模型体验并指定模型 ID
- **THEN** 体验页优先选择该确切模型，不以最近模型覆盖显式选择

#### Scenario: 仅打开目录
- **WHEN** 用户进入模型体验页但未开始会话
- **THEN** 即使已默认选中模型，也不加载权重、不创建推理会话且不申请 GPU

### Requirement: 模型选项展示来源信息
模型选择项及模型详情 SHALL 展示足以区分产物的信息，包括阶段、训练完成时间、来源训练 Run 与原始模型 ID；存在独立合并 Run 时 SHALL 将其与训练 Run 区分展示。

#### Scenario: 查看已合并模型
- **WHEN** 用户查看由训练后合并生成的模型
- **THEN** 页面分别标明训练阶段与训练来源 Run、合并 Run 和原始模型 ID

#### Scenario: 查看基础模型
- **WHEN** 模型没有本地训练 Run 来源
- **THEN** 页面标明其为 Base/外部来源及其模型 ID，不虚构训练时间或来源 Run

### Requirement: 用户显示名管理
用户 SHALL 能为已登记模型填写、修改或清除仅用于展示的名称；名称 SHALL 按不可变模型 ID 关联并保存在当前工作区，且输入 SHALL 有长度限制并作为纯文本展示。

#### Scenario: 新增或修改名称
- **WHEN** 用户为已登记模型提交有效名称
- **THEN** 名称被保存到当前工作区，并立即反映在该模型的展示位置

#### Scenario: 清除名称
- **WHEN** 用户清除已有的用户显示名
- **THEN** 名称元数据被移除，模型恢复系统生成的回退名称

#### Scenario: 无效名称
- **WHEN** 用户提交空白、超长或包含不允许控制字符的名称
- **THEN** 系统拒绝保存并说明可接受的输入范围，既有名称保持不变

### Requirement: 显示名与模型身份隔离
用户显示名 SHALL NOT 替代或更改模型 ID、模型内容摘要、权重文件、Run 标签、训练/合并 Run 身份或 lineage；模型选择与推理请求 SHALL 仍使用不可变模型 ID。

#### Scenario: 使用自定义显示名体验模型
- **WHEN** 用户选择已命名模型并发起体验
- **THEN** 页面使用显示名帮助识别模型，但后端解析和会话仍绑定原始模型 ID

#### Scenario: 核验模型来源
- **WHEN** 用户查看或导出模型及 Run 血缘信息
- **THEN** 原始模型 ID、摘要、训练 Run 和合并 Run 仍可见或可展开查看，且不被显示名覆盖

### Requirement: 一致且兼容的名称呈现
已保存的用户显示名 SHALL 在模型体验选择项、体验结果及 Run 模型产物视图中一致显示；无显示名或旧记录缺少来源时间时，系统 SHALL 使用可读回退名称并保留原始身份信息。

#### Scenario: 展示名称跨视图一致
- **WHEN** 同一模型同时出现在模型体验与其来源 Run 产物视图
- **THEN** 两处显示同一用户显示名，并保留可核对的原始模型 ID

#### Scenario: 兼容既有记录
- **WHEN** 工作区存在未配置用户显示名或不含新来源字段的旧模型记录
- **THEN** 页面仍可展示和选择可用模型，使用阶段、Run 短 ID 或模型 ID 构造回退名称，不要求迁移或重写旧 Run/模型记录
