# Spec Delta

## Purpose

让用户在本地模型体验中明确控制常用解码行为，并通过一致的默认值、参数校验和结果参数摘要理解及复现单聊与模型对照输出。

## ADDED Requirements

### Requirement: 用户可配置模型体验的解码参数
模型体验 SHALL 为单模型对话和同题模型对照提供一致的最大新 Token、Temperature、Top-p、Top-k、重复惩罚及思考模式设置，并提供恢复推荐默认值的操作。

#### Scenario: 初次进入时展示推荐默认值
- **WHEN** 用户打开模型体验页面
- **THEN** 参数默认为最大新 Token 256、Temperature 0.7、Top-p 0.8、Top-k 20、重复惩罚 1.05，且思考模式关闭

#### Scenario: 恢复推荐默认值
- **WHEN** 用户修改参数后选择恢复默认值
- **THEN** 所有参数恢复为页面展示的推荐默认值，后续单聊或对照请求使用这些值

#### Scenario: 单聊与对照使用相同设置
- **WHEN** 用户在任一体验模式提交生成请求
- **THEN** 请求使用当前界面设置的全部参数；模型切换或单聊/对照切换不得静默替换这些参数

### Requirement: 服务端校验并应用有效解码参数
模型体验服务 SHALL 对用户提交的解码参数执行服务端范围与类型校验，并将通过校验的参数应用于实际生成；不支持的字段或无效值 SHALL 返回可理解的错误且不得启动生成。

#### Scenario: 参数在允许范围内
- **WHEN** 用户提交类型正确且范围有效的解码参数
- **THEN** 模型体验按这些参数生成回复，并将 Top-k 为 0 解释为不启用 Top-k 截断

#### Scenario: Temperature 为零时关闭采样
- **WHEN** 用户将 Temperature 设为 0 并提交请求
- **THEN** 系统使用确定性解码，并在结果参数证据中标明 Top-p 和 Top-k 本次未生效

#### Scenario: 参数类型或范围无效
- **WHEN** 用户提交未知参数、错误类型或超出允许范围的值
- **THEN** 服务端拒绝请求并指出无效参数，不加载模型或启动生成

#### Scenario: 思考模式不受模型模板支持
- **WHEN** 用户为不支持思考模式控制的模型启用该选项
- **THEN** 系统明确说明该模型不支持该控制并拒绝本次请求，不得静默忽略该选项或标记其已生效

### Requirement: 生成结果展示实际生效参数
模型体验中的每条成功回复 SHALL 展示该次生成实际生效的完整参数，包括模型是否支持及启用了思考模式；失败结果 SHALL 不得被标记为已按所选参数成功生成。

#### Scenario: 查看单模型回复参数
- **WHEN** 用户查看单模型对话的成功回复
- **THEN** 回复旁显示该次实际生效的全部解码参数

#### Scenario: 查看同题对照参数
- **WHEN** 用户查看同题对照的成功回复
- **THEN** 每个模型的结果显示其实际生效参数，且与该次请求配置一致
