# Spec Delta

## ADDED Requirements

### Requirement: 各阶段普通模型生成可由用户操作
系统 MUST 提供 CPT、SFT、Preference 和 GRPO 普通模型生成入口，支持输入阶段目标或选择兼容训练种子、选择已配置 Provider 与有界预算；浏览、准备及预检不得调用模型，执行必须由用户显式确认。

#### Scenario: 不依赖已有数据集准备普通生成
- **WHEN** 用户以主题等阶段适用的输入准备生成任务但未选择数据集
- **THEN** 系统不伪造父数据集，并检查阶段所需额外证据；缺失证据时可保留草稿或未验证候选，但不得承诺可用于训练

#### Scenario: 准备和预检不触发调用
- **WHEN** 用户选择阶段、Provider 并检查配置，但尚未确认生成
- **THEN** 系统显示预算、风险与阻断原因，实际 Provider 请求数为零

### Requirement: 候选遵循目标阶段契约
系统 MUST 分别生成及校验 CPT 语料、SFT 问答、Preference 同题候选和 GRPO prompt；展示格式、质量及独立语义证据状态，不得以 SFT 格式通过替代其他阶段适配。

#### Scenario: CPT 候选质检
- **WHEN** 用户生成 CPT 领域语料
- **THEN** 系统按连续文本检查格式、长度、重复和可执行的污染覆盖；没有事实核验时显示未验证

#### Scenario: Preference 候选排序
- **WHEN** 用户生成 Preference 数据
- **THEN** chosen/rejected 必须属于同一问题并保留排序依据；正确性排序缺少独立可信验证时不得伪造正误标签或声称已验证

#### Scenario: GRPO 候选缺少可信参考
- **WHEN** 生成的 GRPO prompt 只有模型自报参考答案，或缺少可执行的当前 reward/reference 契约
- **THEN** 系统保留未验证或不符合训练条件的原因，禁止将其当作可信数据启动正式训练

### Requirement: 生成任务可观察且可安全恢复
系统 MUST 持久化阶段、来源模式、执行身份、预算、进度、候选、拒绝原因与终态，并支持刷新恢复及显式取消；恢复或重试不得自动重复未知状态的远程请求。

#### Scenario: 任务部分成功或中断
- **WHEN** 执行达到预算、用户取消或运行中断
- **THEN** 页面显示实际候选与有效/拒绝数量、partial 或失败原因及后续操作，不伪造目标达成，不丢失已持久化结果

### Requirement: 审核登记与训练评测身份交接
系统 MUST 对阶段候选执行可复核的质量审查，并在用户显式审核后登记非空、符合登记规则的完整或 partial 数据；训练和评测分别通过真实身份关联，不得自动启动。

#### Scenario: 登记生成数据后去训练
- **WHEN** 用户确认登记可用数据并选择对应训练阶段
- **THEN** 系统传递精确 dataset ID/hash 与兼容阶段，要求重新预检并显式启动；多来源训练需先使用已登记的组合版本

#### Scenario: 训练和评测结果追溯生成来源
- **WHEN** 用户查看已完成评测的模型来源
- **THEN** 系统能按真实 evaluation、model、train、dataset、quality 和 generation 身份回溯，未发生或缺失证据显示未执行/不完整

### Requirement: 阶段能力与已有历史记录保持真实
系统 MUST 按阶段和来源模式报告实际入口、依赖及阻断；旧 SFT 生成任务、登记数据和身份 MUST 保持可读取，不因迁移产生虚构运行或产物。

#### Scenario: 阶段生成依赖不可用
- **WHEN** Provider、阶段协议、质量验证或必要契约不可用
- **THEN** 用户看到具体不可用原因及可行后续操作，不能看到虚假的可启动或完成状态

### Requirement: 生成模型身份保留可得证据
系统 MUST 在生成执行及来源证据中记录 Provider profile、模型声明、可得 revision 与身份核验状态；只有可核实实际生成服务使用了某项目登记模型时，才可绑定其 model ID 和内容摘要。

#### Scenario: 生成服务使用项目登记模型
- **WHEN** 存在可核实服务实际加载的登记模型身份与内容摘要的证据
- **THEN** 生成记录关联该确切 model ID/hash 及核验状态，可沿模型和 generation execution 回溯

#### Scenario: 外部模型身份不可核实
- **WHEN** 外部 Provider 未提供固定模型 revision、摘要或可核实本地模型身份
- **THEN** 系统保留可得声明并将缺失或无法核验的信息标记为 unknown/unavailable，不根据名称猜测登记 model ID 或摘要

### Requirement: 执行结果可通过稳定身份只读查询
系统 MUST 允许按稳定身份读取生成任务、数据集和质量结果的结构化状态、真实输入与产物引用及证据缺失情况；只读查询 MUST NOT 触发 Provider、登记、训练或评测。

#### Scenario: 恢复观察历史生成任务
- **WHEN** 用户或受控调用方按 execution ID 查询已中断或已完成任务
- **THEN** 返回实际阶段、输入、状态、partial/失败和可用产物身份；不要求解析自由文本日志，不自动启动下一次执行

### Requirement: 数据来源与质量验证证据可区分
系统 MUST 按实际来源区分普通生成、定向生成、原始来源及派生/组合数据，并保留可得祖先和验证方法、版本、状态及实际覆盖分母；未执行的验证不得显示为通过。

#### Scenario: 来源组合与未验证候选
- **WHEN** 数据集包含已登记来源和生成候选，且部分候选没有独立验证
- **THEN** 来源关系和可用验证覆盖分别可查，缺失的验证保持未验证/未测，不从格式通过或合并行为推断正确性
