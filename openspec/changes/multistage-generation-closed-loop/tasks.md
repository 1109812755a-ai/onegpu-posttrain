# 任务清单

- [x] 1.1 对照 `targeted-data-stage-closure` 的 6.2/6.4、`stage-training-evaluation-workbench` 剩余任务和当前实现，输出职责/依赖矩阵；测试或检查验证不会复制既有 Launcher、评测、计划效果页，且不修改其他变更任务状态。
- [x] 1.2 建立按 CPT、SFT、Preference、GRPO 及普通/定向来源模式区分的服务端能力契约与预检；覆盖缺 Provider、阶段协议、验证器、reward/reference 时准确显示阻断，预检/浏览实际 Provider 调用数为零。
- [x] 1.3 将既有 Provider、预算、ledger/cache 和 job 状态封装为带阶段/模式的受控分发，保留 execution ID、进度、partial、失败和取消；测试覆盖刷新恢复、未知请求不自动重试、预算和凭据脱敏。
- [x] 1.4 保持旧 `/api/synthetic/sft/*`、历史 SFT execution、dataset manifest、URL 和身份可读；补充历史 fixture/API 回归，确认不重写、不伪造父集和不自动调用。

## 2. CPT 与 SFT 生成

- [x] 2.1 复用并接通 CPT 领域语料生成 adapter，提供主题/允许的训练种子、token 预算、去重/污染和事实未验证状态；fake Provider 测试覆盖有效、重复、污染、空/partial 和未验证事实。
- [x] 2.2 接通 CPT 普通及定向生成的配置、确认、预览、质检、显式登记与训练交接；API/UI 测试验证计划身份、dataset ID/hash、角色隔离、失败恢复，更新中文 CPT 操作说明。
- [x] 2.3 将现有 SFT 按主题和种子生成接入共享阶段接口与普通/定向入口，保留原有审核与正确性未验证语义；回归两种模式的 Provider 调用确认、登记、历史任务和定向 plan 身份，并更新说明。

## 3. Preference / DPO / SimPO 生成

- [x] 3.1 复用同题候选生成与配对能力，区分可信 reference/独立验证的正确性排序与其他可审计偏好证据；测试双正确、双错误、未知、重复、预算耗尽及不能伪造标签。
- [x] 3.2 接通 Preference 普通和定向生成的预览、排序证据、审核、partial 登记和 DPO/SimPO 交接；API/UI 测试验证两训练分支均消费同一精确 dataset/parent 身份并创建独立 Run，更新中文指南。

## 4. GRPO 生成与可信证据

- [x] 4.1 增加 GRPO 普通和定向模型候选生成适配器，输出阶段 prompt 并记录来源；测试缺可信 reference、模型自报答案、reward 契约不匹配、holdout 祖先和超预算时保持未验证/阻断，不产生可训练伪证。
- [x] 4.2 将可审计的可信 reference/验证构造与版本化可执行 reward 契约接入 GRPO 质检、审核、登记和训练预检；测试成功与失败、partial/零候选和 contract/hash 变化，确保不放宽现有训练 gate。
- [x] 4.3 在数据工作台提供 GRPO 普通/定向生成及既有可信种子派生入口，明确区分“模型生成”和“派生”；UI/API 测试验证显式调用、恢复、精准 dataset 交接和来源许可提醒，并更新中文指南。

## 5. 通用交接、血缘与用户体验

- [x] 5.1 实现普通/定向入口的阶段化表单、清晰操作步骤、Provider 预算与结果预览，支持只读草稿、可见错误和刷新恢复；前端测试覆盖四阶段、两模式、窄屏、切换阶段和未确认零调用。
- [x] 5.2 复用登记、组合、Launcher 和阶段评测能力，将 generation/build/quality/dataset/train/merge/model/evaluation 真实 ID、hash 与可选 plan ID/version 串联；测试根来源、训练种子来源、多数据组合、身份不匹配和失败/缺失证据。
- [x] 5.3 定向计划接入共享阶段数据准备及非模型来源，保留诊断/最终 holdout 隔离、独立的训练与复测确认；测试计划回跳、partial、来源祖先、缺基线或协议不匹配时的未测/不可比呈现，不重复实现原变更的历史与效果页。
- [x] 5.4 对照当前实际阶段能力刷新中文工作台/操作指南与阻断提示；文档 walkthrough 和 UI 测试确认普通生成与定向补数入口、状态和数据交接用词一致，不把导入或种子派生称为模型生成。
- [x] 5.5 保存生成 Provider、模型声明、可得 revision、身份核验状态；当有实际服务加载项目登记模型的可核验证据时关联准确 model ID/hash。测试登记模型匹配、同名但无法证明加载身份、外部版本/摘要缺失，确认不会猜测身份，也不要求本期部署本地模型服务。
- [x] 5.6 复用或扩展受控只读接口，按稳定身份返回生成任务、质量报告、数据集和评测的结构化状态、实际输入/产物、partial/失败及缺失证据；测试多次独立执行和刷新可读取、历史不覆盖，查询不调用 Provider、不启动训练/评测，也不创建虚构轮次。
- [x] 5.7 保留普通/定向生成、原始与派生/组合数据的来源和祖先、验证方法/版本/状态及实际覆盖；保留评测模型与数据集 ID/hash、协议/配置和指标分母及不可得状态。测试真实与合成来源组合、未验证状态、holdout 祖先及协议/身份不匹配时不可比较，不引入自动晋级、回退或下一轮。
