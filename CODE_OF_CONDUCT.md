# Code of Conduct

## Our standard

Contributors should interact professionally, focus criticism on ideas and implementations, and help maintain an environment where technical disagreement can be productive.

Examples of expected behavior include:

- giving reproducible evidence for technical claims;
- acknowledging uncertainty and failed experiments;
- accepting corrections when evidence changes;
- avoiding personal attacks, harassment and discriminatory conduct.

## Scope

This standard applies to project issues, pull requests, discussions and other official project spaces.

## Enforcement

Repository maintainers may edit, hide or remove content and restrict participation when behavior materially disrupts the project or targets contributors personally.
